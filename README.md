# X Korean Word Muter

X(Twitter)에서 지정한 단어가 포함된 게시물을 브라우저에서 직접 필터링하는 Chrome 확장 프로그램입니다.

X 자체 뮤트 기능에서 한글 단어가 원하는 대로 필터링되지 않거나, 사용자가 공백·특수문자 등을 넣어 뮤트를 우회하는 경우를 보완하기 위해 만들었습니다.

현재 버전: v0.2.0


==================================================
1. 주요 기능
==================================================

■ 뮤트 단어 직접 등록

확장 프로그램 팝업에서 원하는 단어나 표현을 직접 등록할 수 있습니다.

각 규칙은 개별적으로 켜고 끌 수 있으므로 삭제하지 않고 일시적으로 비활성화할 수도 있습니다.


■ 한글 / 영문 지원

한글과 영문 모두 사용할 수 있습니다.

일반 문자열 비교에서는 영문 대소문자를 구분하지 않습니다.


■ 우회 표기 탐지

단어 사이에 공백이나 기호 등을 넣어 뮤트를 우회하는 표현을 탐지할 수 있습니다.

예를 들어 다음 규칙을 등록한 경우:

고양이

'우회 표기 포함' 방식에서는 다음과 같은 표현도 탐지할 수 있습니다.

- 고양이
- 고 양 이
- 고.양.이
- 고_양_이
- 고-양-이
- 글자 사이에 제로폭 문자가 포함된 표기

우회 표기 모드는 Unicode NFKC 정규화를 적용한 뒤 공백, 구두점, 기호, 제로폭 문자 등을 제거하여 비교합니다.


■ 새로 로딩되는 게시물 자동 검사

X는 스크롤할 때 게시물을 동적으로 추가하는 구조입니다.

확장 프로그램은 MutationObserver를 사용하여 새롭게 표시되는 게시물도 계속 검사합니다.


■ X의 SPA 페이지 이동 대응

X 내부에서 홈, 검색, 프로필 등으로 이동할 때 전체 페이지가 다시 로딩되지 않는 경우에도 주소 변경을 감지하여 다시 검사합니다.


■ 게시물 숨김 방식 선택

두 가지 방식을 선택할 수 있습니다.

1) 접어서 표시
뮤트된 게시물의 내용을 접고 다음과 같은 안내를 표시합니다.

뮤트됨 · 게시물 · [뮤트 규칙]

'게시물 보기' 버튼을 누르면 해당 게시물을 다시 확인할 수 있습니다.

2) 완전히 숨기기
일치하는 게시물 또는 대상 요소를 화면에서 완전히 숨깁니다.


■ 검사 범위 설정

다음 영역의 검사를 개별적으로 켜고 끌 수 있습니다.

- 게시물 / 인용 게시물
- 게시물 작성자명
- 사용자 목록 / 프로필
- 트렌드
- 검색 결과

검색 결과에 표시되는 일반 게시물은 일반 게시물과 같은 방식으로 필터링됩니다.


■ 사용자명 뮤트

규칙의 대상을 '사용자명'으로 설정하면 게시물 내용이 아니라 작성자 표시 영역을 검사합니다.

규칙 대상은 다음 중 선택할 수 있습니다.

- 글 내용
- 사용자명
- 내용 + 사용자명


■ 인용 게시물 검사

게시물 article 내부에 포함된 여러 tweetText 영역을 함께 검사하므로 일반 게시물뿐 아니라 인용된 게시물의 텍스트도 필터링 대상에 포함될 수 있습니다.


■ 프로필 / 사용자 목록 검사

사용자 목록과 프로필 화면의 사용자 관련 영역도 설정에 따라 검사합니다.


■ 트렌드 검사

트렌드 영역도 뮤트 규칙을 이용하여 검사할 수 있습니다.


■ 설정 내보내기 / 가져오기

현재 설정을 JSON 파일로 내보낼 수 있습니다.

내보낸 JSON 파일을 다시 가져오면 뮤트 규칙과 설정을 복원할 수 있습니다.

백업하거나 다른 Chrome 환경으로 설정을 옮길 때 사용할 수 있습니다.


■ 이전 버전 데이터 변환

v0.1.x에서 사용하던 mutedWords 데이터가 있으면 v0.2.0 형식의 규칙으로 자동 변환하도록 구성되어 있습니다.


==================================================
2. 설치 방법
==================================================

1. 배포된 ZIP 파일의 압축을 풉니다.

2. Chrome 주소창에 다음을 입력합니다.

chrome://extensions

3. 오른쪽 위의 '개발자 모드'를 켭니다.

4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.

5. 압축을 푼 확장 프로그램 폴더를 선택합니다.

예:

x-korean-muter-v0.2.0

6. X가 이미 열려 있었다면 x.com 페이지를 새로고침합니다.

7. Chrome 툴바에서 확장 프로그램 아이콘을 누릅니다.

8. 뮤트할 단어와 원하는 매칭 방식을 등록합니다.


==================================================
3. 업데이트 방법
==================================================

새 버전을 설치할 때는 새 ZIP 파일의 압축을 푼 뒤 새 폴더를 Chrome에 로드하는 방식이 가장 간단합니다.

설정을 보존하고 싶다면 업데이트 전에 팝업의 '설정 내보내기' 기능으로 JSON 백업을 만들어 두는 것을 권장합니다.

새 버전을 설치한 뒤 '설정 가져오기'를 사용하면 백업한 설정을 다시 불러올 수 있습니다.


==================================================
4. 뮤트 규칙 추가 방법
==================================================

확장 프로그램 아이콘을 누르면 설정 팝업이 열립니다.

상단 입력란에 뮤트할 단어나 정규식을 입력합니다.

그다음 다음 두 가지를 선택합니다.

1) 매칭 방식
2) 검사 대상

마지막으로 '추가' 버튼을 누르면 규칙이 저장됩니다.


==================================================
5. 매칭 방식
==================================================

총 네 가지 방식이 있습니다.


--------------------------------------------------
5-1. 우회 표기 포함
--------------------------------------------------

등록 예시:

고양이

잡히는 예시:

- 고양이
- 고 양 이
- 고.양.이
- 고_양_이
- 고-양-이

공백, 구두점, 기호, 제로폭 문자 등을 제거한 뒤 비교합니다.

뮤트 단어 사이에 공백이나 기호를 넣는 우회 표현까지 잡고 싶을 때 사용하는 것을 권장합니다.


--------------------------------------------------
5-2. 부분 포함
--------------------------------------------------

등록 예시:

스포

잡히는 예시:

- 스포
- 스포주의
- 영화스포
- 스포 있음

또 다른 예:

등록:

고양이

잡힘:

- 고양이
- 고양이사진
- 우리집고양이

하지만 다음과 같이 원래 문자열 자체가 달라지면 잡히지 않습니다.

- 고 양 이
- 고.양.이

등록한 문자열이 검사 대상 텍스트 안에 그대로 포함되어 있는지 확인하는 방식입니다.


--------------------------------------------------
5-3. 정확히 일치
--------------------------------------------------

등록 예시:

고양이

잡힘:

- 고양이

잡히지 않음:

- 고양이 사진
- 우리집 고양이
- 고양이 귀여워
- 고 양 이

현재 구현에서는 검사 대상 텍스트 전체가 등록한 값과 같아야 일치합니다.

일반적인 게시물 뮤트보다는 매우 제한적인 조건에 적합합니다.


--------------------------------------------------
5-4. 정규식
--------------------------------------------------

정규식 패턴을 직접 지정하는 고급 기능입니다.

예:

고[\s._-]*양[\s._-]*이

위 정규식은 다음 표현을 탐지할 수 있습니다.

- 고양이
- 고 양 이
- 고.양.이
- 고_양_이
- 고-양-이

또 다른 예:

(스포|스포일러)

다음 표현이 포함된 텍스트를 탐지할 수 있습니다.

- 스포
- 스포일러
- 영화 스포 있음
- 스포일러 주의

잘못된 정규식은 규칙을 추가할 때 차단됩니다.


==================================================
6. 매칭 방식 비교
==================================================

예를 들어 '원신'을 등록한다고 가정합니다.


[우회 표기 포함]

등록값:
원신

원신       → 잡힘
원신유저   → 잡힘
원 신      → 잡힘
원.신      → 잡힘


[부분 포함]

등록값:
원신

원신       → 잡힘
원신유저   → 잡힘
원 신      → 잡히지 않음
원.신      → 잡히지 않음


[정확히 일치]

등록값:
원신

원신       → 잡힘
원신유저   → 잡히지 않음
원 신      → 잡히지 않음
원.신      → 잡히지 않음


[정규식]

등록값:
원[\s.]*신

원신       → 잡힘
원신유저   → 잡힘
원 신      → 잡힘
원.신      → 잡힘


==================================================
7. 어떤 매칭 방식을 사용해야 하나요?
==================================================

일반적인 뮤트 단어
→ '우회 표기 포함' 권장

단어가 원래 형태 그대로 들어간 게시물을 잡고 싶은 경우
→ '부분 포함'

검사 대상 전체가 특정 값과 같을 때만 잡고 싶은 경우
→ '정확히 일치'

여러 표현이나 복잡한 패턴을 하나의 규칙으로 처리하고 싶은 경우
→ '정규식'

대부분의 경우 '우회 표기 포함'을 기본값으로 사용하면 됩니다.

다만 강한 정규화 때문에 원하지 않는 게시물까지 잡히는 단어가 있다면 해당 규칙만 '부분 포함'으로 변경하는 것이 좋습니다.


==================================================
8. 규칙 대상
==================================================

각 뮤트 규칙에는 검사 대상을 지정할 수 있습니다.


■ 글 내용

게시물 본문 등을 대상으로 규칙을 적용합니다.


■ 사용자명

게시물 작성자 표시 영역 등을 대상으로 규칙을 적용합니다.


■ 내용 + 사용자명

글 내용과 사용자명 모두에 같은 규칙을 적용합니다.


==================================================
9. 규칙 ON / OFF
==================================================

등록된 각 규칙 왼쪽의 체크박스를 이용해 개별 규칙을 켜거나 끌 수 있습니다.

규칙을 삭제하지 않고 잠시 사용하지 않을 때 유용합니다.

체크:
규칙 활성화

체크 해제:
규칙 비활성화


==================================================
10. 규칙 삭제
==================================================

등록된 규칙 오른쪽의 '삭제' 버튼을 누르면 해당 규칙을 삭제할 수 있습니다.

잠시 사용하지 않을 목적이라면 삭제보다는 ON/OFF 기능을 사용하는 것을 권장합니다.


==================================================
11. 표시 방식
==================================================

팝업의 '표시 방식'에서 선택할 수 있습니다.


■ 접어서 '게시물 보기' 표시

뮤트 대상 내용을 바로 삭제하지 않고 접어서 표시합니다.

필요한 경우 '게시물 보기'를 눌러 해당 게시물을 다시 확인할 수 있습니다.


■ 완전히 숨기기

뮤트 규칙에 걸린 요소를 화면에서 표시하지 않습니다.


==================================================
12. 검사 범위
==================================================

다음 범위를 개별적으로 설정할 수 있습니다.

■ 게시물 / 인용 게시물

일반 게시물과 게시물 내부의 텍스트를 검사합니다.


■ 게시물 작성자명

게시물 작성자의 사용자명 표시 영역을 검사합니다.


■ 사용자 목록 / 프로필

사용자 목록과 프로필 관련 영역을 검사합니다.


■ 트렌드

X의 트렌드 영역을 검사합니다.


■ 검색 결과

검색 결과에 표시되는 게시물을 필터링하기 위한 설정입니다.


==================================================
13. 설정 백업
==================================================

팝업 아래쪽의 '설정 내보내기'를 누르면 현재 설정을 JSON 파일로 저장할 수 있습니다.

백업 파일에는 뮤트 규칙과 각종 설정이 포함됩니다.

파일명 예:

x-korean-muter-settings-2026-09-12.json


==================================================
14. 설정 복원
==================================================

1. 팝업에서 '설정 가져오기'를 누릅니다.

2. 이전에 내보낸 JSON 설정 파일을 선택합니다.

3. 정상적인 설정 파일이면 규칙과 설정을 불러옵니다.

지원되지 않는 형식의 파일은 가져오지 않습니다.


==================================================
15. 우회 표기 탐지 방식
==================================================

'우회 표기 포함'에서는 단순히 원문 문자열만 비교하지 않습니다.

대략 다음 순서로 텍스트를 정규화합니다.

1. 문자열 변환
2. Unicode NFKC 정규화
3. 영문 대소문자 통일
4. 앞뒤 공백 정리
5. 공백 제거
6. 구두점 제거
7. 기호 제거
8. 제로폭 문자 등 Unicode Format 문자 제거
9. 정규화된 뮤트 단어와 게시물 비교

따라서 일반적인 공백/기호 삽입 우회에 대응할 수 있습니다.


==================================================
16. 주의 사항
==================================================

■ X 페이지 구조 변경

X는 웹페이지의 DOM 구조를 수시로 변경할 수 있습니다.

이 확장 프로그램은 가능한 한 data-testid 기반의 비교적 의미 있는 selector를 사용하고 있지만, X 측 변경으로 일부 기능이 동작하지 않을 수 있습니다.

특히 다음 영역은 X 변경의 영향을 받을 수 있습니다.

- 프로필
- 사용자 목록
- 트렌드
- 검색 화면의 특수 UI

관련 selector는 content.js에서 수정하기 쉽도록 구성되어 있습니다.


■ 우회 표기 모드의 오탐 가능성

'우회 표기 포함'은 공백과 기호 등을 제거한 뒤 비교하기 때문에 일반적인 부분 포함보다 강한 필터입니다.

따라서 기호 자체가 의미를 가지는 단어나 매우 짧은 단어에서는 의도하지 않은 게시물까지 잡힐 가능성이 있습니다.

이 경우 해당 규칙의 방식을 '부분 포함'으로 변경해 주세요.


■ 정규식

정규식은 강력하지만 패턴에 따라 예상보다 많은 게시물이 잡힐 수 있습니다.

정규식을 잘 모르는 경우에는 '우회 표기 포함' 또는 '부분 포함'을 권장합니다.

==================================================
18. 사용 예시
==================================================

예시 1

뮤트하고 싶은 단어:
스포일러

방식:
우회 표기 포함

대상:
글 내용

결과:
'스포일러'뿐 아니라 공백이나 기호를 끼운 일반적인 우회 표기도 함께 필터링합니다.


예시 2

뮤트하고 싶은 사용자명 표현:
특정닉네임

방식:
부분 포함

대상:
사용자명

결과:
작성자 표시 영역에 '특정닉네임'이 포함된 게시물을 필터링합니다.


예시 3

여러 표현을 하나로 처리:

(스포|스포일러)

방식:
정규식

대상:
글 내용

결과:
'스포' 또는 '스포일러' 패턴이 포함된 텍스트를 필터링합니다.


==================================================
19. 권장 기본 설정
==================================================

처음 사용하는 경우 다음 설정을 권장합니다.

매칭 방식:
우회 표기 포함

대상:
글 내용

표시 방식:
처음에는 '접어서 게시물 보기 표시'

검사 범위:
필요한 영역만 활성화

정상적으로 원하는 게시물만 걸러지는 것을 확인한 뒤 '완전히 숨기기'로 변경하면 편리합니다.
