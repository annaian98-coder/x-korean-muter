X Korean Word Muter v0.2.0
============================

설치 / 업데이트
---------------
1. ZIP 압축을 풉니다.
2. chrome://extensions 를 엽니다.
3. 개발자 모드를 켭니다.
4. 처음 설치라면 "압축해제된 확장 프로그램을 로드합니다"를 누르고 이 폴더를 선택합니다.
5. 기존 v0.1.x를 쓰고 있다면 기존 확장을 제거한 뒤 새 폴더를 로드하는 것이 가장 간단합니다.
6. x.com 페이지를 새로고침합니다.

주요 기능
---------
- 단어별 ON/OFF
- 글 내용 / 사용자명 / 둘 다 지정
- 4가지 매칭 방식
  1) 우회 표기 포함
  2) 부분 포함
  3) 정확히 일치
  4) 정규식
- 우회 표기 포함 모드는 Unicode NFKC 정규화 후
  공백, 구두점, 기호, 제로폭 문자를 제거하여 비교
- 예: "고양이", "고 양 이", "고.양.이", "고_양_이", 제로폭 문자가 섞인 표기 대응
- 일반 게시물 및 article 내부 인용 게시물 텍스트 검사
- 게시물 작성자명 뮤트
- 사용자 목록 / 프로필 / 트렌드 검사
- 검색 결과의 게시물은 일반 게시물과 같은 방식으로 필터링
- 완전히 숨기기 / 접어서 다시 보기
- 설정 JSON 내보내기 / 가져오기
- v0.1.x의 mutedWords 데이터를 처음 실행 시 자동 변환

주의
----
X는 웹페이지 DOM 구조를 수시로 변경합니다.
이 확장은 비교적 안정적인 data-testid를 우선 사용하지만,
X 측 변경으로 프로필/트렌드 등 일부 영역이 동작하지 않을 수 있습니다.
그 경우 content.js 상단 CONFIG.selector 또는 프로필 후보 selector만 수정하면
대부분 대응할 수 있도록 구성했습니다.

정규식
------
정규식 모드는 고급 사용자용입니다.
잘못된 정규식은 저장 전에 차단합니다.

우회 표기 모드 주의
-------------------
강한 정규화는 의도적으로 넓게 잡습니다.
예를 들어 기호가 의미를 가지는 단어는 오탐 가능성이 있으므로
그런 단어는 "부분 포함" 또는 "정확히 일치"를 사용하는 것이 좋습니다.
